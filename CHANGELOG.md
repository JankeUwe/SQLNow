## [1.0] — 2026-05-27

### Initial release

ASP.NET web app (dhtmlx) for SQL Server inventory and master-data management. Read-only grids
with alternating row colors and Font Awesome icons. New "Stammdaten" (master data) section with
CRUD forms for 8 tables (Customer, CustomerDomain, ExcludeDB, CompType, DatabaseType,
SQLEntityType, SQLVersion, Support), each with its own handler.
